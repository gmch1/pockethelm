# 选中态、主题与发送模式切换

状态：已发布 0.4.6，验证完成。根据用户要求，Codex 直接实现、review、真机验证及发布，不委派 ZCode。

## 需求与验收

- 排队 / 插入恢复为两项直接点击切换，不打开下拉菜单，不收起键盘。
- 输入中切换保留输入焦点、草稿、光标或选择范围，切换本身不发送消息。
- 统一绿色与中性色主题，增强引擎 Tab、底部导航、筛选项的选中态；不引入新组件库。
- 统一页面边距、按钮高度与控件对齐。顶部名称为 Codex / ZCode，移除实验后缀。
- 使用共享组件保证两引擎一致，保留原发送语义和连接/恢复逻辑。
- 按已有授权发布原商店条目，保留配对与真实会话，使用隔离数据测试输入。
