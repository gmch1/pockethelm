# 合并重复的会话与任务入口

状态：已发布 0.4.11 / 21，Review、真机与公开下载校验完成

## 需求与验收

- 用户指出底部“会话”和“任务”展示相同、切换多余。
- 核对实现后，两者使用同一份 sessions 数据及打开/创建操作，仅计数文案、导航高亮与筛选状态分开，没有独立任务模型。
- 合并成一个“会话”入口，底部仅保留会话、连接；运行中的任务仍通过列表菜单“只看执行中”筛选。
- 两引擎一致，创建/打开会话及返回连接页后继续保留项目筛选；详情页不增加导航。
- 沿用本轮直接实现、验证及商店更新授权，不委派其他 AI。

## 实现与验证

- `WorkspaceUi.kt`：去掉重复任务导航项及列表 tasks 模式参数，计数统一为会话。
- `MainActivity.kt`、`ZcodeScreen.kt`：每个引擎只保留一个列表状态保存键，旧任务页状态仍按会话列表展示；保留连接路由 ID 2，避免旧连接页恢复后跳错位置。
- 更新已有真机回归：两引擎没有任务入口，列表和连接页可切换；合并后从新建详情返回仍保持原项目筛选，搜索和排序继续有效。
